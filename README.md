# 🤖 AI Agent — Azure AI Foundry

> Projeto desenvolvido durante meus estudos em Inteligência Artificial, explorando a criação e configuração de um agente inteligente utilizando **Microsoft Azure AI Foundry e modelos da OpenAI**.

## 📌 Sobre o projeto

Este projeto teve como objetivo explorar, na prática, o desenvolvimento de um **AI Agent** utilizando recursos de Inteligência Artificial Generativa.

O agente foi desenvolvido diretamente no **Azure AI Foundry**, permitindo experimentar conceitos relacionados à configuração de agentes, utilização de modelos de linguagem, definição de instruções e interação com ferramentas.

A proposta do projeto foi compreender como agentes baseados em IA podem ser utilizados para interpretar solicitações, gerar respostas e executar tarefas de maneira orientada a objetivos.

## 🎯 Objetivos

* Explorar o desenvolvimento de agentes utilizando IA Generativa;
* Conhecer o ambiente **Azure AI Foundry**;
* Trabalhar com modelos da **OpenAI**;
* Criar instruções e comportamentos para um agente;
* Testar diferentes interações e respostas;
* Compreender o funcionamento de agentes baseados em LLMs;
* Explorar aplicações práticas de IA em processos e Analytics.

## 🔧 Desenvolvimento

O agente foi configurado no Azure AI Foundry a partir de instruções específicas para definir seu comportamento e objetivo.

Durante o desenvolvimento foram explorados conceitos como:

* Definição de instruções para o agente;
* Configuração do modelo;
* Engenharia de prompts;
* Testes de diferentes entradas;
* Avaliação das respostas geradas;
* Ajustes no comportamento do agente;
* Exploração de ferramentas e recursos disponibilizados pela plataforma.

## 💡 Funcionamento

O fluxo básico da solução consiste em:

**1. Entrada**

O usuário envia uma solicitação ao agente.

**2. Interpretação**

O modelo analisa a solicitação considerando as instruções definidas para o agente.

**3. Processamento**

O agente utiliza os recursos configurados para processar a solicitação.

**4. Resposta**

O modelo gera uma resposta baseada no contexto e nas instruções estabelecidas.
